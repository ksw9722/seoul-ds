# AI-DLC 진행 기록

AI-DLC를 이름만 붙인 체크리스트가 아니라 **결정·변경·검증 증거가 연결되는 개발 주기**로 사용합니다. 사용자 요구와 위험을 먼저 정리하고, 변경 범위를 작게 나누며, 실행 결과와 미검증 범위를 구분합니다. 자동 테스트가 실제 기기 검증을 대신하지 않습니다.

| 단계 | 산출물 | 통과 조건 |
|---|---|---|
| Inception / 요구 | [requirements.md](requirements.md) | 범위, 제외 항목, 승인, 수용 기준이 명시됨 |
| Construction / 설계 | [design.md](design.md) | 원작 코어 재사용 이유, 데이터·생명주기·파일 권한 위험 설명 |
| Construction / 구현 | Git 변경 이력, [변경 기록](../CHANGELOG.md) | 파일별 변경 추적 가능, GPL 고지 유지 |
| Construction / 검증 | [검증 행렬](../testing/verification-status.md), 하네스 로그 | 각 검사를 PASS/FAIL/BLOCKED/NOT RUN으로 구분 |
| Operations / 배포 | [releasing.md](../releasing.md) | APK/정확한 소스/해시/검증 제한 동시 제공 |

## 승인·결정 기록

- 2026-11-01: 사용자는 Galaxy S24 개인용 DS 에뮬레이터 개발을 요청했고, 이후 공개 배포 가능성을 밝혔다.
- 2026-11-01: melonDS Android GPL 기반 수정 앱과 대응 소스 공개 방향을 승인했다. 개발 완료 후 사용자 GitHub에 공개 저장소 생성·공개를 요청했다. 실제 공개 대상과 게시 결과는 배포 담당자가 확인한다.
- 2026-11-01: Android SDK/NDK 약관 링크를 제시한 후 설치·약관 동의를 명시적으로 승인했다. 이 기록은 **이번 개발 환경**의 승인 기록이며 다른 사용자의 동의를 대신하지 않는다. CI 도구 설치는 저장소 관리자의 `ANDROID_SDK_LICENSE_ACCEPTED=true` 설정을 별도로 요구한다.
- 실제 Galaxy S24, 사용자가 적법하게 확보한 게임 파일, 원본 BIOS 파일에 접근하지 않았다. 게임 ROM을 인터넷에서 다운로드하지 않는다.

## 단계 경계

소스 준비 완료, APK 생성 완료, CI 완료, 실기기 검증 완료, 공개 배포 완료는 서로 다른 상태다. 하나의 완료를 다른 완료로 보고하지 않는다. 미완료 단계는 이유와 재개 조건을 남긴다. 최신 실행 증거는 하네스의 UTC 타임스탬프·Git 커밋·작업 트리 상태와 함께 보존한다.
