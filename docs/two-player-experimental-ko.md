# 한 기기 2P 통신 실험 기능

## 목적과 검증 범위

한 Android 기기에서 두 DS를 동시에 실행하고, 화면과 조작 대상을 1P/2P로 전환하는 방식입니다. 서로 다른 전화 두 대를 연결하는 LAN 기능이나 Nintendo WFC 서비스가 아닙니다.

**포켓몬 통신 교환의 실기기 성공은 아직 확인하지 않았습니다.** 소스 검사나 패킷/단위 테스트 통과는 게임 내 상대 검색, 교환 완료 또는 교환 후 저장의 검증을 대신하지 않습니다.

## 안전 원칙

- 시작 전에 두 게임의 게임 내부 저장 파일을 별도로 백업합니다. 상태 저장 파일은 통신 교환용 저장 파일을 대신하지 않습니다.
- 두 DS가 같은 저장 파일에 동시에 기록하면 안 됩니다. 두 번째 플레이어는 별도의 지속 저장 파일을 사용해야 합니다.
- 두 DS는 서로 다른 인스턴스 ID와 펌웨어 MAC을 사용합니다.
- 통신 모드는 1배속만 사용합니다. 상태 저장/불러오기, 되감기, 단독 재시작은 두 DS의 시간과 상태를 어긋나게 하므로 통신 중 사용하지 않습니다.
- 최초 범위는 DS와 소프트웨어 렌더러입니다. DSi, 두 전화 연결, 인터넷 통신 및 하드코어 업적 기능은 별도 범위입니다.
- 한 플레이어의 화면을 보고 있어도 다른 DS가 실행을 계속해야 합니다. 앱을 백그라운드로 보내거나 대화상자를 열어 정지할 때에는 두 DS를 함께 정지해야 합니다.

## 사용 흐름 (Android 실행 검증 대기)

1. 설정에서 DS 모드와 소프트웨어 렌더러를 선택하고 게임을 시작합니다. 먼저 1P 게임 안에서 저장해 백업할 세이브 파일을 만듭니다.
2. 일시정지 메뉴의 실험적 2P 항목에서 경고를 읽고 2P 세이브를 가져오거나 새 세이브로 시작합니다. 기존 P2가 있다면 계속하기를 선택할 수 있습니다.
3. 플레이어 전환으로 1P와 2P를 번갈아 조작합니다. 다른 플레이어도 실행 중이므로 게임 내 통신 화면을 양쪽에서 준비합니다.
4. 종료 전 양쪽 게임 안에서 저장합니다. 같은 2P 메뉴에서 현재 P2 세이브와 최신 시작 전 P1 백업을 내보낼 수 있습니다.
5. P2 복사본과 내부 백업은 앱 데이터에 저장되므로 앱 삭제/데이터 초기화 전에 반드시 내보냅니다. 다른 P2 세이브로 교체하기 전에도 현재 P2를 먼저 외부에 내보내세요.

## 실제 게임 검증 체크리스트 (미실행)

1. 사용자가 합법적으로 보유한 ROM과 서로 다른 두 게임 내부 세이브의 복사본을 준비합니다.
2. 일반 1P의 부팅·터치·버튼·오디오·게임 내부 저장이 기존과 같은지 확인합니다.
3. 2P 취소/실패 시 1P가 유지되고 원본 세이브가 변경되지 않는지 확인합니다.
4. 2P를 시작하고 플레이어 전환을 반복합니다. 이전 플레이어의 버튼/터치가 눌린 채 남지 않는지 확인합니다.
5. 같은 게임의 지원되는 통신 장소에서 상대 검색부터 연결까지 확인합니다.
6. 중요하지 않은 포켓몬으로 교환을 끝내고 양쪽 게임 내부 저장을 완료합니다.
7. 두 인스턴스를 종료하고 각각의 세이브로 다시 부팅합니다. 교환 결과가 양쪽에 보존됐는지 확인합니다.
8. 앱 배경 전환, 화면 회전, 종료/재실행, 통신 실패, 저장 공급자 오류와 공간 부족을 검사합니다.
9. 성공한 게임명·지역/버전, Android 버전, 기기, 설정, 빌드 커밋과 절차를 기록합니다. 다른 게임이나 버전에 결과를 일반화하지 않습니다.

어느 단계라도 실패하면 세이브 백업을 보존하고 해당 빌드를 안정적인 통신 교환용으로 사용하지 않습니다.
