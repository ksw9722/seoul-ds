# 개인정보·권한 안내

Seoul DS의 새 시작/설정 안내는 로컬에서 동작하며 별도의 계정·광고·분석 서버를 추가하지 않습니다. 이는 앱의 모든 기능이 네트워크를 사용하지 않는다는 뜻은 아닙니다. 원작의 선택적 RetroAchievements, 네트워크 관련 에뮬레이션, DSi 메타데이터 기능 등이 남아 있습니다. 기본 DS 로컬 사용과 추가 온라인 기능을 구분하세요.

## 로컬 데이터

ROM 폴더의 문서 URI, 설정, ROM 목록/메타데이터, 저장 파일과 상태 저장은 원작 저장 방식에 따라 앱 전용 또는 사용자가 선택한 저장소에 기록됩니다. 파일 자체를 보유할 권리는 사용자가 확인해야 합니다. 저장소 공급자가 클라우드 드라이브이면 해당 공급자의 동기화/보관 정책도 적용됩니다.

RetroAchievements에 직접 로그인하면 원작 `AndroidRAUserAuthStore`가 사용자명과 인증 토큰을 앱 private SharedPreferences에 저장합니다. 이 토큰은 별도 앱 수준 암호화를 추가한 것으로 주장하지 않습니다. 해당 기능을 쓰지 않으려면 로그인하지 않거나 로그아웃하세요. 게임 식별·도전과제·리더보드 요청은 RetroAchievements로 전송될 수 있습니다.

## Android 권한

- **문서 폴더 접근:** 사용자가 시스템 문서 선택기에서 지정한 범위. 전체 저장소 접근 권한을 새로 요구하지 않습니다.
- **마이크/카메라:** 원작 DS 마이크/DSi 카메라 관련 선택 기능. Android가 묻는 경우 필요하지 않으면 거부할 수 있습니다.
- **인터넷/Wi-Fi/근처 기기:** 원작 온라인/네트워크 관련 기능. 이 포크가 모든 통신을 차단했다고 주장하지 않습니다.
- **알림/백그라운드 작업/진동:** 원작 백그라운드 작업 알림과 터치 반응 등에 사용될 수 있습니다.

원작 APK를 이 앱의 업데이트로 내려받는 경로는 새 포크에서 비활성화하며, 서명된 독립 업데이트 채널이 준비될 때까지 업데이트는 수동입니다.

## 삭제·백업·이슈 보고

앱 삭제/데이터 삭제는 앱 전용 설정과 저장 데이터 유실을 일으킬 수 있습니다. 사용자가 선택한 문서 폴더의 파일은 별도로 관리해야 합니다. Android 백업·복원 범위는 앱 설정과 플랫폼 정책을 따르므로 이것만 믿지 말고 세이브를 별도 백업하세요.

이슈에는 ROM/BIOS, 세이브의 민감 정보, 문서 URI, 계정 토큰, 키 파일, 프록시 인증정보를 올리지 마세요. 공개 로그는 개인 경로/계정/인증값을 먼저 가립니다. 이 저장소는 사용자의 기기 정보나 게임 파일을 자동으로 수집하는 신고 도구를 추가하지 않습니다.
