# Galaxy S24에서 시작하기

이 문서는 **실기기 테스트 완료 안내가 아니라 설치 후 확인할 절차**입니다. S24 모델/Android 버전에 따라 문구·폴더 선택 화면이 다를 수 있습니다.

1. 개발 APK와 SHA-256을 신뢰할 수 있는 이 프로젝트 배포 위치에서 함께 받습니다. 정식 서명이 아닌 디버그 빌드는 개인 테스트용으로 취급하세요.
2. 설치 파일을 여는 앱에 한해서 Android의 출처별 설치 허용이 필요할 수 있습니다. 기기 보안 기능을 전역으로 끄거나 우회하지 마세요. 관리 기기 정책이 설치를 막으면 관리자 정책을 따릅니다.
3. Seoul DS의 처음 실행 안내를 읽습니다. 상용 게임 ROM이나 기기에서 추출한 BIOS는 제공하지 않습니다. 사용권을 확보한 `.nds` 파일 또는 본인이 만든 홈브루를 준비하세요. 이 앱은 게임 다운로드를 도와주지 않습니다.
4. ROM 전용 하위 폴더를 만들고 앱의 ROM 폴더 설정에서 Android 문서 선택기로 그 폴더를 선택합니다. 폴더의 루트, Downloads 전체, `Android/data` 등은 Android 버전/공급자 정책상 선택이 제한될 수 있으므로 **사용자 문서 안의 별도 하위 폴더**가 편합니다.
5. "이 폴더 사용" 등 시스템 확인이 나오면 필요한 범위만 허용합니다. 취소해도 됩니다. 파일을 옮기거나 외장 저장소를 제거하거나 권한을 회수하면 폴더를 다시 선택해야 합니다. URI 권한은 영구적인 접근 보장이 아닙니다.
6. 기본 DS 직접 부팅은 원작 FreeBIOS와 생성 펌웨어를 사용합니다. 임의의 인터넷 BIOS 파일을 찾을 필요가 없습니다. 실제 펌웨어 화면 부팅과 DSi 모드는 다른 조건이며 이 MVP의 검증 목표가 아닙니다.
7. 먼저 비상용·적법한 테스트 콘텐츠로 화면·터치·소리·저장을 확인한 뒤 자신의 게임을 실행합니다. 성공 여부는 [기기 검증표](testing/s24-device-checklist.md)에 기록합니다.

## 저장을 잃지 않기

- **게임 내부 저장:** 게임 메뉴에서 저장한 진행도입니다. 장기 진행에 우선 사용하세요.
- **상태 저장/퀵 세이브:** 에뮬레이터의 순간 상태입니다. 앱/코어 버전이 바뀌면 호환되지 않을 수 있고 내부 저장과 같지 않습니다.
- 저장 중 앱을 강제 종료하거나 저장 폴더를 이동하지 마세요. 진행도가 중요하면 앱을 정상 종료한 뒤 저장 폴더를 별도 백업하세요.
- 원작 앱과 Seoul DS는 설치 ID가 다르므로 개인 앱 저장소가 자동으로 공유되지 않습니다. 앱 삭제/데이터 지우기 전 사용자 저장 폴더를 확인하고 백업해야 합니다.
- 새 버전 설치 전 세이브를 복사하고, 테스트용 복사본에서 저장→종료→재실행→불러오기를 확인하세요. 이 문서는 무손실 저장 보증이 아닙니다.

## 막힐 때

| 증상 | 먼저 확인할 것 |
|---|---|
| 목록이 비어 있음 | 올바른 ROM 하위 폴더/권한/파일 확장자, 다시 검색 |
| 폴더 선택을 취소함 | 설정에서 다시 선택. 취소를 오류/완료로 간주하지 않음 |
| 저장 실패 | 폴더 쓰기 권한, 저장 공간, 클라우드 공급자 연결. 원본 세이브부터 별도 보존 |
| 느림·끊기는 소리 | 기본 해상도/렌더러 기준으로 재확인, 발열·절전·백그라운드 앱 기록 |
| 특정 게임만 실패 | 기기/Android/앱 버전과 재현 절차를 기록. 호환 보장이나 우회 패치를 제공하지 않음 |

기능을 설명하는 자료와 검증 결과를 혼동하지 마세요. 설치·권한·게임 실행 단계는 아직 사용자의 기기에서 확인이 필요합니다.
