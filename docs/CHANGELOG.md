# 변경 기록

## 0.1.0-alpha01 · 2026-11-01 · 최초 Seoul DS 포크

기반: melonDS Android 2.0.1 (`5ec3648d68382dea9c17d6fbf02544e5c2c0afed`). 원작 저작권/라이선스 및 네이티브 하위 모듈 출처 유지.

- 독립 application ID·이름·자체 브랜드 리소스, 선택 가능한 ARM64 빌드.
- 권장 개인 테스트 프로필은 네이티브 RelWithDebInfo 최적화와 개발 서명 APK를 결합하며, 실제 그래프/패키지 GNU build ID 일치를 별도 검사.
- 한국어 시작·설정 상태 안내와 파일 선택/저장 설명, 설정 복귀 시 권한 기록 갱신.
- SAF 폴더 선택 시 검증·지속 권한 확보 후에만 설정을 갱신하여 취소·권한 오류로 기존 선택을 잃지 않게 함.
- 저장/불러오기 중복 실행 억제와 네이티브 프레임 경계·종료 동기화 가드; [동시성 설계](save-safety-ko.md).
- 반복 가능한 검증 하네스, 소스 패키징 도구, 한국어 AI-DLC/실기기 테스트/배포 문서.
- 알파 버전은 상태 저장 후 자동 썸네일 생성을 생략: 종료 시 원작 프레임 대기 교착 위험을 피하고 자리 표시자로 표시.
- 원작 게임 화면 이미지와 상류 자동 배포 워크플로 제거. 남은 DSiWare 워드마크/멜론 알림 PNG는 자체 일반 벡터로 교체하고 사용하지 않는 웹 런처 PNG 제거.

정확한 구현 변경은 Git diff와 커밋을 기준으로 합니다. 빌드/단위 테스트 결과와 실기기 테스트 결과는 [검증 현황](testing/verification-status.md)에 별도로 기록합니다. 특정 게임이나 Galaxy S24 호환성을 검증 완료한 릴리스가 아닙니다.
